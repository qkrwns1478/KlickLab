# 프론트엔드 미사용 코드 및 타입 오류 정리

## 작업 내용

### 1. 사용되지 않는 파일 삭제
`src/main.tsx`에서 시작하는 import 그래프로 도달할 수 없는 파일을 삭제했다.

- 컴포넌트: `Summary`, `ClickTrend`, `AverageSessionDurationCard`, `RealtimeUserCart`, `components/dashboard/*`(Dashboard.tsx 제외), `acquisition/TopChannelBarChart`, `settings/SegmentFilterManager`, `ui/FilterTabs`, `ui/SegmentFilterBuilder`, `user/TreeSankey`
- 주석 처리된 라우트로만 참조되던 파일: `traffic/TrafficDashboard`, `traffic/PathExplorer`, `traffic/TopPageFromMainPage`, `ui/GlobalFilterBar`, `conversion/SankeyFunnel`, `sankey/CustomLink`, `sankey/CustomNode`
- 훅/유틸: `useOverviewWidgets`, `useRealtimeData.js`, `useRealtimeOverview`, `getPageLabel`, `overviewApi`, `performanceUtils`, `segmentStorage`
- 데모용 목업 데이터: `data/mockData.ts`, `data/engagementMock.ts`, `data/eventCountsMock.ts`, `data/types.ts`, `data/channelConversionMockData.json`
- 에셋: `assets/react.svg`

### 2. 목업 데이터 의존 제거
- `UserPathSankeyChart`: 데이터가 없을 때 `mockSankeyPaths` 대신 빈 배열을 사용 (기존의 빈 데이터 처리 로직이 그대로 동작)
- `ChannelConversionTable`: API 실패 시 목업 JSON 대신 빈 배열로 대체
- `ConversionDashboard`, `EngagementDashboard`: 사용하지 않던 목업 import 제거

### 3. 사용되지 않는 import/변수 제거
`tsc`(noUnusedLocals/Parameters) 및 ESLint `no-unused-vars` 지적 사항을 정리했다. (`dayjs`, 차트 컴포넌트 import, 미사용 state/핸들러 등)

### 4. 타입 오류 수정
- `ConversionEventContext`: Context 값 타입 정의, `children` 타입 지정, 훅이 Provider 밖에서 호출되면 에러를 던지도록 변경
- `OverviewDashboard`: `forwardRef` 제네릭 타입(`OverviewDashboardHandle`, `OverviewDashboardProps`) 지정
- `InfoWidgetsSection`: `WidgetFrame`, `SimpleTable` props 타입 정의
- `EngagementOverview`: 유니온 배열 `.map` 분기 분리, `ChartWrapper` `onSelect` 캐스팅
- `DateRangeSelector`: 날짜 범위 타입에 `key` 추가, `@types/react-date-range` 설치, 라이브러리에 없는 `showSelectionPreview` prop 제거
- `UserPathSankeyChart`: `svgRef`가 연결되지 않아 동작하지 않던 상위 컴포넌트의 d3 `useEffect` 제거(단계 헤더용 `depths`는 `useMemo`로 대체), 툴팁 state 타입 지정, d3-sankey 콜백 매개변수 타입 지정
- 그 외 `catch (err)` 미사용 바인딩, `prefer-const`, 비정상 공백 문자 수정
